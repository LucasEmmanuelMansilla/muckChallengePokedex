# muckChallengePokedex

App React Native con una pantalla de **Hola mundo**.

## Requisitos

Completa la [guía de entorno](https://reactnative.dev/docs/set-up-your-environment).

## Ejecutar

```sh
npm start
```

En otra terminal:

```sh
npm run android
# o
npm run ios
```

En iOS, la primera vez:

```sh
bundle install
bundle exec pod install
```
